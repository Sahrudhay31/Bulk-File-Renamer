# 🔑 Keyword Bulk Renamer (Google Apps Script)

Bulk rename files in Google Drive using keyword rules.

## Features
- Search folders by name
- Prefix / Suffix / Standardize naming
- Live preview before renaming
- Works with shared drives

## Tech Stack
- Google Apps Script
- Google Drive API
- HTML + Bootstrap

## Setup
1. Open Google Apps Script
2. Create new project
3. Paste Code.gs and Index.html
4. Enable Drive API
5. Deploy as Web App
